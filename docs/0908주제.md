# 삭제된 로그 연구

주제

- 별도의 로깅(VPC Flow Logs, S3 Access Logs, Config 등)을 사전에 활성화하지 않아도, AWS 계정 생성 시점부터 **기본적으로(Always-On) 동작하며 절대 끌 수 없는 데이터 소스**
- CloudTrail 로그가 없어지는 상황에서도 AWS 리소스의 상태 변화를 통해 공격 행위를 추정

```
                     AWS Account
                         │
          ┌──────────────┴──────────────┐
          │                             │
      CloudTrail                    AWS Resources
          │                             │
          │ StopLogging                │
          ▼                             │
     EventBridge                       │
          │                             │
          ▼                             │
       Lambda ◄─────────────────────────┘
          │
          │ Boto3
          ▼
  ┌───────────────────┐
  │ Resource Collector │
  └─────────┬─────────┘
            │
    ┌───────┼────────┐
    ▼       ▼        ▼
   EC2     S3       IAM
    │       │        │
    └───────┼────────┘
            ▼

		└───────┬────────┘
		        ▼
		Attack Reconstruction
```

Resource
| 서비스 | 주요 필드 | 설명 |
| :--- | :--- | :--- |
| **EC2** | • InstanceID<br>• LaunchTime<br>• ImageId<br>• VPC Id | 컴퓨팅 자원의 고유 식별자, 부팅 시각, 그리고 백도어 주입 여부를 추적할 수 있는 원본 AMI 기원을 제공합니다. |
| **S3** | • Bucket ARN<br>• CreationTime<br>• Region | 버킷의 명칭과 최초 생성 시각을 통해 데이터 저장소의 기원을 증명하며, 객체 매니페스트를 통해 대규모 삭제·변조 흔적을 포착합니다. |
| **IAM** | • UserID<br>• RoleId<br>• CreateDate | 권한 닻인 `RoleId`와 생성 시각을 고정하여, 공격자가 백도어 권한이나 지속성을 확보하기 위해 몰래 생성한 롤을 100% 잡아냅니다. |
| **IAM Access Key** | • AccessKeyId<br>• CreateDate<br>• UserName | 장기 자격 증명의 고유 ID와 발급 시각을 통해, 시스템 뒤피로 은밀히 발급된 외부 접근 키의 존재를 확증합니다. |
| **EBS Volume** | • VolumeId<br>• CreateTime<br>• SourceVolumeId | 볼륨의 고유 식별자와 생성 시각뿐만 아니라, 스냅샷의 원본 혈통을 통해 랜섬웨어 및 데이터 무단 복제·유출 궤적을 추적합니다. |
